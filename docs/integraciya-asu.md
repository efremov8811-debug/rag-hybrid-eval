# Интеграция с АСУ ТП

## Поддерживаемые протоколы

Modbus RTU по RS-485: поддерживается всеми приборами с цифровым выходом — ДД-300,
РВ-40, РВ-40И, ТМ-10 в исполнении с цифровым выходом.
HART 7 поверх токовой петли: ДД-200 и ДД-300.
Аналоговый 4–20 мА: все серии, кроме РВ-40И.
Импульсный выход: РВ-40 и РВ-40И.

Протоколы Profibus, Foundation Fieldbus и Ethernet/IP напрямую не поддерживаются.
Для подключения к таким сетям применяются шлюзы сторонних производителей, которые
мы поставляем под заказ.

## Параметры связи Modbus RTU

Скорость по умолчанию: 9600 бод. Поддерживаются 4800, 9600, 19200, 38400, 57600,
115200 бод.
Формат кадра по умолчанию: 8 бит данных, без контроля чётности, 2 стоп-бита (8N2).
Адрес устройства по умолчанию: 1. Диапазон адресов: от 1 до 247.
Максимальное число приборов на одном сегменте: 32 без повторителя, до 247 с
повторителями.
Максимальная длина линии: 1200 метров на скорости 9600 бод, 200 метров на 115200 бод.

Важно: при смене скорости и формата кадра изменения вступают в силу только после
перезапуска питания прибора.

## Карта регистров, общая часть

Регистры хранения, функция чтения 0x03, функция записи 0x06 и 0x10.

40001–40002: текущее измеренное значение, формат float32, порядок слов CD AB.
40003: код единицы измерения, uint16.
40004: статус прибора, битовая маска uint16.
40010: сетевой адрес, uint16, запись.
40011: код скорости обмена, uint16, запись.
40020–40021: верхний предел измерений, float32.
40022–40023: нижний предел измерений, float32.

Битовая маска статуса: бит 0 — обрыв датчика, бит 1 — выход за верхний предел,
бит 2 — выход за нижний предел, бит 3 — требуется поверка, бит 4 — ошибка
энергонезависимой памяти.

Порядок слов CD AB означает, что младшее слово числа float32 передаётся первым.
В ряде SCADA-систем по умолчанию установлен порядок AB CD, в этом случае значение
читается как мусор и порядок слов нужно переключить в настройках опроса.

## Карта регистров, только расходомеры

40030–40031: накопленный объём прямого направления, float32, м3.
40032–40033: накопленный объём обратного направления, float32, м3.
40034–40035: время наработки, uint32, часы.
40040: номер записи архива для чтения, uint16, запись.
40041–40050: содержимое выбранной записи архива.

Чтение архива выполняется в два шага: сначала записывается номер записи в регистр
40040, затем читается блок 40041–40050. Чтение блока без предварительной записи
номера возвращает последнюю выбранную запись.

## Типичные ошибки подключения

Нет ответа от прибора: проверить согласующие резисторы 120 Ом на обоих концах линии,
полярность A и B, совпадение скорости и формата кадра.
Ответ с ошибкой CRC: как правило, слишком длинная линия для выбранной скорости либо
отсутствие общего провода между сегментами.
Значение читается как мусор: несовпадение порядка слов float32.
Прибор отвечает только при отключении соседних: совпадающие сетевые адреса.
